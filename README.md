# BS VR Manager

A Beat Saber **mod manager that runs in VR** — and as a normal desktop window.

- One Beat Saber copy per game version; imports your existing BSManager profiles
- Download any Beat Saber version (pinned by Steam depot manifest, background downloads)
- Browse and install mods from BeatMods with dependency resolution; BSIPA handled
- In VR: three laser-driven floating panels around you; without a headset it runs as a
  normal desktop window

## Download

Grab the latest release from the
[Releases page](https://github.com/FudgeCZ/bsvr-manager/releases) or the [itch.io](https://fudgee.itch.io/bsvr-manager) page.
Unzip, run the exe, and log in to Steam once in Settings to enable version downloads.

## Requirements

- Windows 10+ (x64)
- A Steam copy of Beat Saber
- Any OpenXR runtime for VR mode (SteamVR, Virtual Desktop, …)
